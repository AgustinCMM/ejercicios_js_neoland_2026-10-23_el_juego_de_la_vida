2. Generador de Cajas

Consigna

Tip general para esta sección: Dividan el problema en pasos pequeños. Primero asegúrense de que la lógica en JavaScript funciona usando console.log, y solo cuando estén seguros de que los datos son correctos, pasen a manipular el DOM.

Crea un arreglo con 5 nombres de colores en inglés (ej. ["red", "blue", "green", "yellow", "purple"]). Recorre el arreglo y por cada color, crea un div en el HTML que tenga ese color de fondo, 100px de ancho y alto, usando manipulación de clases CSS desde JS.
