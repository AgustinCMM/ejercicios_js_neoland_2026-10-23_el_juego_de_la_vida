10. Capitalizador de Palabras

Consigna

Tip general para esta sección: Dividan el problema en pasos pequeños. Primero asegúrense de que la lógica en JavaScript funciona usando console.log, y solo cuando estén seguros de que los datos son correctos, pasen a manipular el DOM.

Tienes un arreglo: ["hola", "mundo", "javascript", "es", "genial"]. Crea una función que recorra el arreglo y capitalice solo la primera letra de cada palabra, devolviendo un nuevo texto unido: "Hola Mundo Javascript Es Genial".
